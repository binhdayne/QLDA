# Analysis artifacts

This repository contains the project-data model and planning analysis produced with spreadsheet and project-management tools for the QLDA middleware MVP.

## Included analyses
- WBS and schedule import data (CSV and MS Project interchange XML).
- Resource capacity, effort, labor-equivalent cost, risks, test plan, and project controls (Excel workbook).
- Structured baseline assumptions used to generate the management artifacts (JSON).

## Reproduction notes
These are planning artifacts, not measured production results. Dates, rates, and effort are estimates; confirm them with the team and course instructor. Workbook previews in the PDF are rendered from the workbook and are not MS Project screenshots. No live customer data or credentials are included.
